## Descripciones listas para copiar

### Definir objetivo del proyecto
Determinar el propósito de TaskFlow, sus usuarios y las funciones necesarias para la primera versión.

### Preparar estructura del repositorio
Crear archivos HTML, CSS y JavaScript, además de la documentación y carpetas del proyecto.

### Diseñar la interfaz del tablero
Diseñar las columnas del tablero, las tarjetas y la adaptación a computadoras y celulares.

### Programar movimiento de tareas
Agregar la lógica que permita cambiar una tarea de un estado a otro.

### Guardar tareas en el navegador
Utilizar localStorage para conservar el estado de las tarjetas cuando se recarga la página.

### Validar diseño en móvil
Comprobar que el contenido se vea correctamente en pantallas pequeñas.

### Revisar documentación
Verificar que el README explique el objetivo, la estructura y cómo ejecutar el proyecto.

### Publicar repositorio y tablero
Subir el repositorio a GitHub, crear el Project, ponerlo público y copiar el enlace para entregar.
