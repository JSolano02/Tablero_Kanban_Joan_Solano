# Tablero Kanban Joan Solano

Proyecto académico preparado para practicar planificación de tareas con **GitHub Projects** usando una vista tipo **Kanban**.

> Importante: el tablero que se entrega al profesor se crea en GitHub Projects y debe quedar **público**. Este repositorio contiene una pequeña aplicación de ejemplo y todos los textos/tareas necesarios para montar el tablero sin improvisar.

## Proyecto de ejemplo

La idea del repositorio es una mini aplicación web llamada **TaskFlow**, que permite visualizar tareas en cuatro estados:

- Por hacer
- En proceso
- En revisión
- Finalizado

La aplicación está hecha solamente con HTML, CSS y JavaScript, por lo que no necesita instalar dependencias.

## Cómo ejecutar

1. Descarga o clona este repositorio.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` en el navegador o usa la extensión **Live Server**.
4. El tablero local funcionará inmediatamente.

## Entrega de la práctica

Para completar la práctica debes crear en tu cuenta de GitHub un **Project** llamado:

**Tablero Kanban Joan Solano**

Luego usa las tareas de `docs/TAREAS_PARA_GITHUB_PROJECTS.md`, organiza las columnas y deja el proyecto en visibilidad pública.

La guía completa está en:

- `docs/PASOS_DESDE_CERO.md`
- `docs/TAREAS_PARA_GITHUB_PROJECTS.md`
